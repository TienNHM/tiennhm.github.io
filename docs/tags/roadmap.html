00. Lộ trình học SQL

03. SELECT, WHERE

Giới thiệu cách sử dụng SELECT và WHERE trong SQL. Học cách truy vấn dữ liệu từ bảng, lọc dữ liệu với điều kiện WHERE.

04. ORDER BY, LIMIT

Giới thiệu cách sử dụng ORDER BY và LIMIT trong SQL. Học cách sắp xếp kết quả truy vấn và giới hạn số lượng hàng trả về.

05. Toán tử, Biểu thức

Giới thiệu cách sử dụng toán tử và biểu thức trong SQL. Học cách so sánh, kết hợp điều kiện và thực hiện các phép toán trong truy vấn SQL.

06. INSERT - UPDATE - DELETE

Học cách Chỉnh sửa (thêm, cập nhật và xóa) dữ liệu trong SQL. Tìm hiểu cách thực hiện các thao tác CRUD (Create, Read, Update, Delete) trên bảng.

07. Review 1

09. GROUP BY - HAVING

Giới thiệu về GROUP BY và HAVING trong SQL, cách sử dụng và ví dụ minh họa.

10. JOIN

Giới thiệu về các loại JOIN trong SQL, cách sử dụng và ví dụ minh họa.

11. Truy vấn con (Subquery)

Giới thiệu về truy vấn con (Subquery) trong SQL, cách sử dụng và ví dụ minh họa.

12. UNION - INTERSECT

Giới thiệu về truy vấn hợp nhất (UNION) và truy vấn giao nhau (INTERSECT) trong SQL, cách sử dụng và ví dụ minh họa.

13. CASE WHEN

Giới thiệu về điều kiện trong SQL, cách sử dụng CASE WHEN để xử lý điều kiện trong truy vấn SQL, cách sử dụng và ví dụ minh họa.

14. Review 2

Kiểm tra kiến thức - Bài tập tổng hợp cho tuần 2 học SQL.

15. Index

Giới thiệu về Index trong SQL, cách tạo và sử dụng Index, cách tối ưu truy vấn SQL với Index.

16. Transactions - ACID

Giới thiệu về Transactions trong SQL, cách sử dụng và đảm bảo tính nhất quán dữ liệu với ACID.

17. Stored Procedures & Functions

Giới thiệu về Stored Procedures và User Defined Functions (UDF) trong SQL.

18. Triggers

Tìm hiểu cách sử dụng Triggers để tự động hóa kiểm soát dữ liệu trong SQL.

19. Views

Tìm hiểu cách sử dụng Views để đơn giản hóa truy vấn trong SQL.

20. Query Performance

Tìm hiểu cách phân tích và tối ưu hiệu suất truy vấn SQL bằng EXPLAIN ANALYZE.

22. SQL Json practice

Giới thiệu về kiểu dữ liệu JSON trong SQL và cách truy vấn dữ liệu JSON trong SQL.

23. SQL connect apps

Hướng dẫn kết nối SQL với ứng dụng và thực hành tạo API CRUD đơn giản.

24. Import - Export data

Hiểu cách nhập dữ liệu từ file CSV, Excel vào SQL, xuất dữ liệu từ SQL ra file CSV, Excel và sử dụng các lệnh LOAD DATA INFILE, COPY, SELECT INTO OUTFILE để xử lý dữ liệu.

25. Big Data

Làm việc với dữ liệu lớn (Big Data) trong SQL - Partitioning, Sharding, Compression.

26. SQL - NoSQL

So sánh SQL (Quan hệ) và NoSQL (Phi quan hệ) - Khi nào nên dùng SQL và NoSQL, so sánh MySQL, PostgreSQL vs. MongoDB, Firebase.

27. Database design best practices

Thiết kế cơ sở dữ liệu (Database Design) - Nguyên tắc chuẩn hóa CSDL, khi nào nên phi chuẩn hóa, best practices thiết kế CSDL hiệu quả.

28. SQL query optimization

Hướng dẫn tối ưu hóa truy vấn SQL, phân tích truy vấn với EXPLAIN ANALYZE, tránh lỗi phổ biến khi viết SQL, tận dụng Index, Partition, Caching để tăng hiệu suất.

29. Recursive Queries & Window Functions

Giới thiệu về Recursive Queries và Window Functions trong SQL, cách viết truy vấn đệ quy, ứng dụng thực tế, cách sử dụng Window Functions để phân tích dữ liệu, xếp hạng, lọc dữ liệu theo thời gian.

30. Database security

Học cách quản trị & bảo mật database, phân quyền, ngăn chặn SQL Injection, sao lưu & khôi phục dữ liệu đúng cách.
