# 16.8 — 7. FluentValidation

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

Gắn validation **gần contract** của use case, tách khỏi entity nếu rule chỉ là “input shape” (định dạng) chứ không phải invariant lõi.

```csharp
public class CreateLeadCommandValidator : AbstractValidator<CreateLeadCommand>
{
    public CreateLeadCommandValidator()
    {
        RuleFor(x => x.Email).NotEmpty().EmailAddress();
        RuleFor(x => x.FullName).MaximumLength(200);
    }
}
```

Có thể tích hợp behavior MediatR: validate trước khi vào handler.
