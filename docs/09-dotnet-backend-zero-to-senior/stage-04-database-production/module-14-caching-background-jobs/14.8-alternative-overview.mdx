## Nội dung bài học

### 14.8.1 — Khi nào dùng Quartz thay Hangfire?

| Tiêu chí | Hangfire | Quartz.NET |
|----------|----------|-----------|
| **Lưu trữ job** | Database (SQL/Redis) | Database hoặc RAM |
| **Dashboard** | Có sẵn | Cần tự build |
| **Retry** | Tích hợp | Tự implement |
| **Clustering** | Tốt | Rất tốt (built-in) |
| **Job chaining** | Có | Có (Job listeners) |
| **Trigger phức tạp** | Hạn chế | Mạnh (Calendar, Cron) |
| **License** | LGPL (free) | Apache 2.0 |

**Chọn Quartz khi:** Cần trigger phức tạp (lịch nghỉ, múi giờ), clustering cao cấp, hoặc không muốn overhead của Hangfire Dashboard.

### 14.8.2 — Trigger Types trong Quartz

```csharp
// Simple Trigger: lặp lại N lần với khoảng cách cố định
ITrigger simpleTrigger = TriggerBuilder.Create()
    .WithSimpleSchedule(s => s
        .WithIntervalInHours(1)
        .RepeatForever())
    .Build();

// Cron Trigger: cú pháp cron đầy đủ
ITrigger cronTrigger = TriggerBuilder.Create()
    .WithCronSchedule("0 0 8 * * ?") // 8:00 AM mỗi ngày
    .Build();

// Calendar Interval: bỏ qua ngày lễ
ITrigger calendarTrigger = TriggerBuilder.Create()
    .WithCalendarIntervalSchedule(s => s
        .WithIntervalInWeeks(1)
        .SkipDayIfHourDoesNotExist(true))
    .Build();
```

### 14.8.3 — Job Chaining với Listeners

```csharp
public class LeadSyncJobListener : IJobListener
{
    public string Name => "LeadSyncListener";

    public Task JobWasExecuted(IJobExecutionContext context,
        JobExecutionException? jobException, CancellationToken ct)
    {
        if (jobException is null)
        {
            // Trigger job tiếp theo
            var nextJob = JobBuilder.Create<NotifyAgentJob>().Build();
            var trigger = TriggerBuilder.Create().StartNow().Build();
            context.Scheduler.ScheduleJob(nextJob, trigger, ct);
        }
        return Task.CompletedTask;
    }
    // ...
}
```
