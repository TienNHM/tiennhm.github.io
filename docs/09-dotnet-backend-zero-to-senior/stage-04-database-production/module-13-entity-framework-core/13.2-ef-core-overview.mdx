# 13.2 — 1. EF Core Overview

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### 13.2.1 — ORM là gì?

ORM (Object-Relational Mapper) ánh xạ giữa bảng trong RDBMS và class trong C#, giúp lập trình viên thao tác dữ liệu qua object thay vì viết SQL thuần.

**EF Core** là ORM chính thức của Microsoft, hỗ trợ SQL Server, PostgreSQL, MySQL, SQLite và nhiều provider khác.

### 13.2.2 — Code-First so với Database-First

| Hướng tiếp cận | Mô tả | Khi nào dùng |
|---|---|---|
| **Code-First** | Định nghĩa entity class → EF sinh schema | Dự án mới, team kiểm soát schema |
| **Database-First** | DB có sẵn → `Scaffold-DbContext` sinh code | Legacy DB, DBA quản lý schema |
| **Model-First** | Thiết kế visual → sinh cả code lẫn DB | Ít dùng trong thực tế |

> Khóa học này dùng **Code-First** — phổ biến nhất trong team .NET hiện đại.

### 13.2.3 — EF Core so với Dapper so với ADO.NET

| | EF Core | Dapper | ADO.NET thuần |
|---|---|---|---|
| **Abstraction** | Cao — LINQ → SQL | Trung bình — SQL + mapping | Thấp — SQL hoàn toàn |
| **Tốc độ phát triển** | Nhanh nhất | Trung bình | Chậm nhất |
| **Performance** | Tốt (với tuning) | Rất tốt | Tốt nhất |
| **Migrations** | Có sẵn | Không | Không |
| **Dùng khi** | CRUD phức tạp, domain model rõ | Reporting, complex query, cần tốc độ tối đa | Micro-optimization, stored proc nặng |
| **Không dùng khi** | Bulk insert triệu dòng | Domain model phức tạp | Team thiếu SQL skill |

**Khuyến nghị thực tế**: Dùng EF Core làm default; kết hợp Dapper hoặc `FromSqlRaw` cho query phức tạp cần performance cao.
