# 13.7 — 6. N+1 Problem

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### 13.7.1 — Ví dụ N+1 (SART: sẽ gây hại)

```csharp
// ĐỪNG làm thế này
var customers = await _db.Customers.ToListAsync(); // 1 query

foreach (var c in customers)
{
    // Mỗi customer gọi THÊM 1 query → N+1 queries!
    var contactCount = await _db.Contacts
        .CountAsync(ct => ct.CustomerId == c.Id);
    Console.WriteLine($"{c.Name}: {contactCount} contacts");
}
```

**SQL log sẽ thấy:**
```
SELECT * FROM Customers                          -- 1 query
SELECT COUNT(*) FROM Contacts WHERE CustomerId=1 -- query #2
SELECT COUNT(*) FROM Contacts WHERE CustomerId=2 -- query #3
... (N thêm queries cho N customers)
```

### 13.7.2 — Fix 1: Dùng Include

```csharp
var customers = await _db.Customers
    .Include(c => c.Contacts)  // JOIN trong 1 query
    .AsNoTracking()
    .ToListAsync();

foreach (var c in customers)
    Console.WriteLine($"{c.Name}: {c.Contacts.Count} contacts");
```

### 13.7.3 — Fix 2: Projection (tốt hơn khi chỉ cần count)

```csharp
var result = await _db.Customers
    .AsNoTracking()
    .Select(c => new {
        c.Name,
        ContactCount = c.Contacts.Count()
    })
    .ToListAsync();
```

### 13.7.4 — Fix 3: AsSplitQuery cho nhiều collection

```csharp
// Include nhiều collection → cartesian explosion
// AsSplitQuery tách thành nhiều query riêng, tránh duplicate row
var customers = await _db.Customers
    .Include(c => c.Contacts)
    .Include(c => c.Leads)
    .AsSplitQuery()   // EF Core 5+
    .AsNoTracking()
    .ToListAsync();
```

```csharp

{

```
