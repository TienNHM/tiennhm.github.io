### 13.1.4 — 13.4 — Phương pháp học tập

Bài học này được dẫn dắt theo chu trình học tập chủ động:

1. **Khởi động tư duy**: bắt đầu bằng câu hỏi gợi mở để kích hoạt kiến thức nền.
2. **Kiến tạo kiến thức**: học khái niệm cốt lõi đi kèm ví dụ có ngữ cảnh.
3. **Luyện tập có hướng dẫn**: áp dụng qua mini case và ví dụ thực tế ngắn.
4. **Tự đánh giá và phản tư**: dùng checklist + bài thực hành để chốt năng lực.

> Mục tiêu là bạn hiểu sâu, dùng được ngay, và tự đánh giá được mức độ nắm bài.

### 13.1.5 — 13.5 — Mục tiêu học tập

Sau module này, học viên có thể:

- Cấu hình `DbContext` và mapping entity với Fluent API cho domain CRM
- Quản lý database schema bằng migrations, seeding và rollback
- Nhận biết và sửa N+1 problem; chọn đúng loading strategy
- Áp dụng các kỹ thuật performance: `AsNoTracking`, bulk operations, `ExecuteUpdate/Delete`
- Xử lý optimistic concurrency conflict trong môi trường nhiều người dùng
- Triển khai Repository + Unit of Work pattern phù hợp với EF Core
- Cấu hình Global Query Filters cho soft delete và multi-tenant
