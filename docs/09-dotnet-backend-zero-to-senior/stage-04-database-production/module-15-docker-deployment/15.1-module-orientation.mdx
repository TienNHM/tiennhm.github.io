### 15.4 — Phương pháp học tập

Bài học này được dẫn dắt theo chu trình học tập chủ động:

1. **Khởi động tư duy**: bắt đầu bằng câu hỏi gợi mở để kích hoạt kiến thức nền.
2. **Kiến tạo kiến thức**: học khái niệm cốt lõi đi kèm ví dụ có ngữ cảnh.
3. **Luyện tập có hướng dẫn**: áp dụng qua mini case và ví dụ thực tế ngắn.
4. **Tự đánh giá và phản tư**: dùng checklist + bài thực hành để chốt năng lực.

> Mục tiêu là bạn hiểu sâu, dùng được ngay, và tự đánh giá được mức độ nắm bài.

### 15.5 — Mục tiêu học tập

Sau module này, học viên có thể:

- Viết Dockerfile multi-stage tối ưu cho ASP.NET Core API
- Dựng `docker-compose.yml` cho stack CRM đầy đủ (API, DB, Redis, logging)
- Thiết lập GitHub Actions pipeline: build → test → push image → deploy
- Deploy ứng dụng lên Linux VPS với nginx reverse proxy và SSL
- Hiểu các lựa chọn Azure và khi nào dùng loại nào
- Cấu hình structured logging, health check, và uptime monitoring
- Nắm khái niệm Kubernetes cơ bản và khi nào cần dùng
- Sử dụng .NET Aspire cho local development orchestration
