# 15.8 — 7. Azure Deployment

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### So sánh các lựa chọn Azure

| Dịch vụ | Use case | Độ phức tạp | Chi phí |
|---|---|---|---|
| **App Service** | Web app, API truyền thống | Thấp | Trung bình |
| **Container Apps** | Microservice, scale to zero | Trung bình | Thấp-trung |
| **AKS** | Enterprise, nhiều service | Cao | Cao |
| **Azure Functions** | Event-driven, serverless | Thấp | Rất thấp |

Cho CRM monolith: **Azure Container Apps** là lựa chọn tốt — auto-scale, managed, giá hợp lý.

### Deploy từ GitHub Actions lên Azure Container Apps

```yaml
- name: Login to Azure
  uses: azure/login@v2
  with:
    creds: ${{ secrets.AZURE_CREDENTIALS }}

- name: Deploy to Azure Container Apps
  uses: azure/container-apps-deploy-action@v1
  with:
    resourceGroup: crm-rg
    containerAppName: crm-api
    imageToDeploy: ${{ env.REGISTRY }}/${{ env.IMAGE_NAME }}:latest
```

### Các dịch vụ Azure hỗ trợ

- **Azure SQL Database**: managed SQL Server, auto backup, geo-replication
- **Azure Cache for Redis**: managed Redis, bật TLS mặc định
- **Azure Container Registry (ACR)**: private registry, tích hợp sẵn với ACA/AKS
- **Azure Key Vault**: quản lý secrets, certs, keys

### Pricing Mindset

- Luôn bật **cost alerts** trên Azure Portal.
- Container Apps billing: CPU/memory theo giây khi có request. Scale to zero = $0 khi idle.
- Dev/Staging environment: dùng B1/Free tier, không để chạy 24/7 nếu không cần.
