### 9.1.4 — 9.4 — Phương pháp học tập

Bài học này được dẫn dắt theo chu trình học tập chủ động:

1. **Khởi động tư duy**: bắt đầu bằng câu hỏi gợi mở để kích hoạt kiến thức nền.
2. **Kiến tạo kiến thức**: học khái niệm cốt lõi đi kèm ví dụ có ngữ cảnh.
3. **Luyện tập có hướng dẫn**: áp dụng qua mini case và ví dụ thực tế ngắn.
4. **Tự đánh giá và phản tư**: dùng checklist + bài thực hành để chốt năng lực.

> Mục tiêu là bạn hiểu sâu, dùng được ngay, và tự đánh giá được mức độ nắm bài.

### 9.1.5 — 9.5 — Mục tiêu học tập

Sau module này, học viên có thể:

- Thiết kế RESTful API theo đúng nguyên tắc: resource-based URL, HTTP verbs, status codes.
- Cấu hình API versioning và viết tài liệu OpenAPI/Swagger chuyên nghiệp.
- Implement pagination, filtering, sorting linh hoạt trên `IQueryable`.
- Xử lý upload/download file (disk, Azure Blob) và streaming.
- Áp dụng rate limiting, response caching, output caching để bảo vệ API.
- Viết integration test với `WebApplicationFactory` và `HttpClient`.
- Triển khai background service để xử lý tác vụ nền (gửi email digest CRM).

### 9.1.6 — 9.6 — Câu hỏi khởi động

- Nếu không có kiến thức trong bài này, hệ thống CRM/ERP sẽ gặp rủi ro gì?
- Trong dự án thực tế, bạn nghĩ phần kiến thức này nằm ở tầng nào (API, nghiệp vụ, dữ liệu, vận hành)?
- Dấu hiệu nào cho thấy bạn đã hiểu bản chất bài học (không chỉ nhớ định nghĩa)?

## Bài tập áp dụng

1. Tóm tắt bài học bằng ngôn ngữ của bạn.
2. Liên hệ nội dung với một tình huống thực tế trong dự án.
3. Đề xuất một cải tiến cụ thể sau khi học bài này.
