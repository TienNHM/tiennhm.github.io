# 9.9 — 8. API Testing

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### 8.1 WebApplicationFactory setup

```csharp
// CrmApiFactory.cs
public class CrmApiFactory : WebApplicationFactory<Program>
{
    protected override void ConfigureWebHost(IWebHostBuilder builder)
    {
        builder.ConfigureServices(services =>
        {
            // Thay DB thật bằng in-memory
            var descriptor = services.SingleOrDefault(d =>
                d.ServiceType == typeof(DbContextOptions<CrmDbContext>));
            if (descriptor != null) services.Remove(descriptor);

            services.AddDbContext<CrmDbContext>(options =>
                options.UseInMemoryDatabase("TestDb_" + Guid.NewGuid()));
        });
    }
}
```

### 8.2 Integration test Customer API

```csharp
public class CustomerApiTests : IClassFixture<CrmApiFactory>
{
    private readonly HttpClient _client;

    public CustomerApiTests(CrmApiFactory factory)
    {
        _client = factory.CreateClient();
    }

    [Fact]
    public async Task GetCustomers_ReturnsPagedResult()
    {
        var response = await _client.GetAsync("/api/v1/customers?page=1&pageSize=10");
        response.EnsureSuccessStatusCode();

        var result = await response.Content
            .ReadFromJsonAsync<PagedResponse<CustomerDto>>();

        Assert.NotNull(result);
        Assert.NotNull(result.Pagination);
        Assert.True(result.Pagination.PageSize <= 10);
    }

    [Fact]
    public async Task CreateCustomer_WithInvalidEmail_Returns422()
    {
        var payload = new { name = "Test", email = "not-valid-email" };
        var response = await _client.PostAsJsonAsync("/api/v1/customers", payload);

        Assert.Equal(HttpStatusCode.UnprocessableEntity, response.StatusCode);
    }

    [Fact]
    public async Task GetCustomer_NotFound_Returns404()
    {
        var response = await _client.GetAsync("/api/v1/customers/99999");
        Assert.Equal(HttpStatusCode.NotFound, response.StatusCode);
    }

    [Fact]
    public async Task GetCustomers_WithSearch_ReturnsFilteredResult()
    {
        // Arrange: seed data
        var createResp = await _client.PostAsJsonAsync("/api/v1/customers",
            new { name = "Nguyễn Văn A", email = "a@crm.vn", status = "active" });
        createResp.EnsureSuccessStatusCode();

        // Act
        var response = await _client.GetAsync("/api/v1/customers?search=Nguyễn");
        var result = await response.Content.ReadFromJsonAsync<PagedResponse<CustomerDto>>();

        // Assert
        Assert.True(result!.Data.Any(c => c.Name.Contains("Nguyễn")));
    }
}
```

> **Postman collection:** Export collection JSON từ Postman và commit vào `tests/postman/` để QA và onboarding nhanh. Sử dụng environment variables (`{{baseUrl}}`, `{{token}}`) để chạy trên nhiều môi trường.
