# 9.8 — 7. Response Caching và Output Caching

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### 7.1 ResponseCache attribute

```csharp
// Cache 60s, vary theo Authorization header
[HttpGet("{id}")]
[ResponseCache(Duration = 60, VaryByHeader = "Authorization", Location = ResponseCacheLocation.Any)]
public async Task<IActionResult> GetCustomer(int id) { ... }

// Không cache (dữ liệu nhạy cảm)
[HttpGet("profile")]
[ResponseCache(NoStore = true, Location = ResponseCacheLocation.None)]
public IActionResult GetProfile() { ... }
```

### 7.2 Output Caching (.NET 7+)

```csharp
// Program.cs
builder.Services.AddOutputCache(options =>
{
    options.AddBasePolicy(b => b.Expire(TimeSpan.FromSeconds(10)));
    options.AddPolicy("customers-list", b =>
        b.Expire(TimeSpan.FromMinutes(2))
         .SetVaryByQuery("page", "pageSize", "search", "status")
         .Tag("customers"));
});

app.UseOutputCache();

// Controller
[HttpGet]
[OutputCache(PolicyName = "customers-list")]
public async Task<IActionResult> GetCustomers([FromQuery] CustomerFilterParams @params) { ... }

// Invalidate cache khi có thay đổi
[HttpPost]
public async Task<IActionResult> CreateCustomer(
    CreateCustomerRequest request,
    IOutputCacheStore cache,
    CancellationToken ct)
{
    // ... tạo customer
    await cache.EvictByTagAsync("customers", ct); // xóa cache danh sách
    return CreatedAtAction(nameof(GetCustomer), new { id = customer.Id }, customer);
}
```
