## 1. REST API Design Principles

### 1.1 Nguyên tắc cốt lõi

REST (Representational State Transfer) dựa trên các ràng buộc: **stateless**, **client-server**, **cacheable**, **uniform interface**, **layered system**.

**Resource-based URL** — URL định danh tài nguyên, không phải hành động:

```
# Đúng
GET    /api/v1/customers
GET    /api/v1/customers/{id}
POST   /api/v1/customers
PUT    /api/v1/customers/{id}
PATCH  /api/v1/customers/{id}
DELETE /api/v1/customers/{id}

# Nested resource
GET    /api/v1/customers/{id}/contacts
POST   /api/v1/customers/{id}/contacts

# Sai (hành động trong URL)
POST   /api/v1/getCustomers
POST   /api/v1/deleteCustomer
```

**HTTP verbs đúng chỗ:**

| Verb   | Mục đích              | Idempotent | Safe |
|--------|-----------------------|------------|------|
| GET    | Đọc dữ liệu           | Có         | Có   |
| POST   | Tạo mới               | Không      | Không|
| PUT    | Thay thế toàn bộ      | Có         | Không|
| PATCH  | Cập nhật một phần     | Không      | Không|
| DELETE | Xóa                   | Có         | Không|

### 1.2 10 Golden Rules REST

| #  | Quy tắc |
|----|---------|
| 1  | Dùng danh từ số nhiều cho resource: `/customers`, `/orders` |
| 2  | Dùng HTTP verbs thay vì động từ trong URL |
| 3  | Trả về status code đúng: 200, 201, 204, 400, 404, 409, 422, 500 |
| 4  | Versioning từ ngày đầu: `/api/v1/...` |
| 5  | Pagination bắt buộc với danh sách |
| 6  | Dùng HTTPS, không bao giờ HTTP cho production |
| 7  | Xác thực lỗi rõ ràng: `{ errors: [...] }` |
| 8  | Stateless — mỗi request chứa đủ thông tin |
| 9  | Hỗ trợ filtering, sorting, field selection |
| 10 | Tài liệu hóa API (OpenAPI/Swagger) |

> **HATEOAS** (Hypermedia As The Engine Of Application State) — cấp độ cao nhất của REST: mỗi response trả về links dẫn đến các action liên quan. Trong thực tế enterprise ít dùng toàn bộ, nhưng nên trả về `_links` cho pagination.

## 2. API Versioning

### 2.1 Các chiến lược versioning

```csharp
// Cài đặt NuGet
// dotnet add package Asp.Versioning.Mvc
// dotnet add package Asp.Versioning.Mvc.ApiExplorer

// Program.cs
builder.Services.AddApiVersioning(options =>
{
    options.DefaultApiVersion = new ApiVersion(1, 0);
    options.AssumeDefaultVersionWhenUnspecified = true;
    options.ReportApiVersions = true; // Header: api-supported-versions
    options.ApiVersionReader = ApiVersionReader.Combine(
        new UrlSegmentApiVersionReader(),           // /api/v1/customers
        new HeaderApiVersionReader("X-Api-Version"), // Header
        new QueryStringApiVersionReader("api-version") // ?api-version=1.0
    );
})
.AddApiExplorer(options =>
{
    options.GroupNameFormat = "'v'VVV";
    options.SubstituteApiVersionInUrl = true;
});
```

### 2.2 Controller versioning

```csharp
[ApiController]
[Route("api/v{version:apiVersion}/customers")]
[ApiVersion("1.0")]
public class CustomersV1Controller : ControllerBase
{
    [HttpGet]
    public IActionResult GetAll() => Ok(new { version = "v1" });
}

[ApiController]
[Route("api/v{version:apiVersion}/customers")]
[ApiVersion("2.0")]
[ApiVersion("1.0", Deprecated = true)] // đánh dấu deprecated
public class CustomersV2Controller : ControllerBase
{
    [HttpGet]
    public IActionResult GetAll() => Ok(new { version = "v2", enhanced = true });
}
```

Khi version bị deprecated, header `api-deprecated-versions` sẽ được tự động trả về để client biết và migrate.

## 4. Pagination, Filtering, Sorting

### 4.1 Pagination params và response envelope

```csharp
public record PaginationParams
{
    public int Page { get; init; } = 1;
    public int PageSize { get; init; } = 20;
    public int Skip => (Page - 1) * PageSize;
}

public record CustomerFilterParams : PaginationParams
{
    public string? Search { get; init; }
    public string? Status { get; init; }       // active, inactive, lead
    public DateTime? CreatedFrom { get; init; }
    public DateTime? CreatedTo { get; init; }
    public string? SortBy { get; init; } = "createdAt";
    public string? SortDir { get; init; } = "desc"; // asc | desc
}

public record PagedResponse<T>
{
    public IEnumerable<T> Data { get; init; } = [];
    public PaginationMeta Pagination { get; init; } = new();
}

public record PaginationMeta
{
    public int Page { get; init; }
    public int PageSize { get; init; }
    public int Total { get; init; }
    public int TotalPages => (int)Math.Ceiling((double)Total / PageSize);
    public bool HasNext => Page < TotalPages;
    public bool HasPrev => Page > 1;
}
```

Response envelope:
```json
{
  "data": [ { "id": 1, "name": "Nguyễn Văn A" } ],
  "pagination": {
    "page": 1,
    "pageSize": 20,
    "total": 150,
    "totalPages": 8,
    "hasNext": true,
    "hasPrev": false
  }
}
```

### 4.2 IQueryable filtering + sorting

```csharp
public class CustomerQueryService
{
    public IQueryable<Customer> ApplyFilter(IQueryable<Customer> query, CustomerFilterParams p)
    {
        if (!string.IsNullOrWhiteSpace(p.Search))
            query = query.Where(c => c.Name.Contains(p.Search) || c.Email.Contains(p.Search));

        if (!string.IsNullOrWhiteSpace(p.Status))
            query = query.Where(c => c.Status == p.Status);

        if (p.CreatedFrom.HasValue)
            query = query.Where(c => c.CreatedAt >= p.CreatedFrom.Value);

        if (p.CreatedTo.HasValue)
            query = query.Where(c => c.CreatedAt <= p.CreatedTo.Value);

        // Dynamic sorting
        query = (p.SortBy?.ToLower(), p.SortDir?.ToLower()) switch
        {
            ("name", "asc")        => query.OrderBy(c => c.Name),
            ("name", "desc")       => query.OrderByDescending(c => c.Name),
            ("createdat", "asc")   => query.OrderBy(c => c.CreatedAt),
            _                      => query.OrderByDescending(c => c.CreatedAt)
        };

        return query;
    }
}
```

### 4.3 Customer list endpoint hoàn chỉnh

```csharp
[HttpGet]
[ProducesResponseType(typeof(PagedResponse<CustomerDto>), StatusCodes.Status200OK)]
public async Task<IActionResult> GetCustomers([FromQuery] CustomerFilterParams @params)
{
    var query = _db.Customers.AsNoTracking();
    query = _queryService.ApplyFilter(query, @params);

    var total = await query.CountAsync();
    var items = await query
        .Skip(@params.Skip)
        .Take(@params.PageSize)
        .Select(c => new CustomerDto(c.Id, c.Name, c.Email, c.Status, c.CreatedAt))
        .ToListAsync();

    return Ok(new PagedResponse<CustomerDto>
    {
        Data = items,
        Pagination = new PaginationMeta
        {
            Page = @params.Page,
            PageSize = @params.PageSize,
            Total = total
        }
    });
}
```

> **Cursor pagination** phù hợp hơn offset khi dataset lớn (hàng triệu bản ghi) vì tránh `OFFSET` scan. Sử dụng `cursor` là giá trị cuối của trường sort thay vì số trang.

## 5. File Upload và Download

### 5.1 Upload avatar khách hàng

```csharp
[HttpPost("{id}/avatar")]
[RequestSizeLimit(5 * 1024 * 1024)] // 5MB
[ProducesResponseType(typeof(FileUploadResult), StatusCodes.Status200OK)]
public async Task<IActionResult> UploadAvatar(int id, IFormFile file)
{
    // Validate
    var allowedTypes = new[] { "image/jpeg", "image/png", "image/webp" };
    if (!allowedTypes.Contains(file.ContentType))
        return BadRequest("Chỉ hỗ trợ JPEG, PNG, WebP.");

    if (file.Length > 5 * 1024 * 1024)
        return BadRequest("File tối đa 5MB.");

    var ext = Path.GetExtension(file.FileName).ToLowerInvariant();
    var fileName = $"avatar-{id}-{Guid.NewGuid()}{ext}";

    // Lưu disk (hoặc thay bằng Azure Blob)
    var uploadPath = Path.Combine(_env.WebRootPath, "uploads", "avatars");
    Directory.CreateDirectory(uploadPath);

    var fullPath = Path.Combine(uploadPath, fileName);
    await using var stream = System.IO.File.Create(fullPath);
    await file.CopyToAsync(stream);

    // Cập nhật DB
    var customer = await _db.Customers.FindAsync(id)
        ?? throw new NotFoundException($"Không tìm thấy customer {id}");
    customer.AvatarUrl = $"/uploads/avatars/{fileName}";
    await _db.SaveChangesAsync();

    return Ok(new FileUploadResult(fileName, customer.AvatarUrl));
}
```

### 5.3 Streaming download báo cáo

```csharp
[HttpGet("export")]
public async Task<IActionResult> ExportCustomers([FromQuery] CustomerFilterParams @params)
{
    var query = _db.Customers.AsNoTracking();
    query = _queryService.ApplyFilter(query, @params);

    // Stream CSV để tránh load toàn bộ vào memory
    var stream = new MemoryStream();
    await using var writer = new StreamWriter(stream, leaveOpen: true);
    await writer.WriteLineAsync("Id,Name,Email,Status,CreatedAt");

    await foreach (var c in query.AsAsyncEnumerable())
        await writer.WriteLineAsync($"{c.Id},{c.Name},{c.Email},{c.Status},{c.CreatedAt:O}");

    await writer.FlushAsync();
    stream.Position = 0;

    return File(stream, "text/csv", $"customers-{DateTime.UtcNow:yyyyMMdd}.csv");
}
```

## 6. Rate Limiting (.NET 7+)

```csharp
// Program.cs
builder.Services.AddRateLimiter(options =>
{
    options.RejectionStatusCode = StatusCodes.Status429TooManyRequests;

    // Fixed window: 100 req / 1 phút cho tất cả
    options.AddFixedWindowLimiter("fixed", o =>
    {
        o.PermitLimit = 100;
        o.Window = TimeSpan.FromMinutes(1);
        o.QueueProcessingOrder = QueueProcessingOrder.OldestFirst;
        o.QueueLimit = 10;
    });

    // Sliding window: mượt hơn fixed window
    options.AddSlidingWindowLimiter("sliding", o =>
    {
        o.PermitLimit = 60;
        o.Window = TimeSpan.FromMinutes(1);
        o.SegmentsPerWindow = 6;
    });

    // Per-user rate limiting dựa trên JWT sub
    options.AddPolicy("per-user", context =>
    {
        var userId = context.User.FindFirst(ClaimTypes.NameIdentifier)?.Value ?? "anonymous";
        return RateLimitPartition.GetTokenBucketLimiter(userId, _ => new()
        {
            TokenLimit = 20,
            TokensPerPeriod = 10,
            ReplenishmentPeriod = TimeSpan.FromSeconds(10),
            AutoReplenishment = true
        });
    });
});

app.UseRateLimiter();
```

```csharp
// Áp dụng cho controller
[HttpGet]
[EnableRateLimiting("per-user")]

// Hoặc disable cho internal endpoint
[HttpGet("health")]
[DisableRateLimiting]
public IActionResult Health() => Ok();
```

## 9. Background Processing với Hosted Service

### 9.1 BackgroundService cơ bản

```csharp
// EmailDigestWorker.cs
public class EmailDigestWorker : BackgroundService
{
    private readonly IServiceScopeFactory _scopeFactory;
    private readonly ILogger<EmailDigestWorker> _logger;

    public EmailDigestWorker(IServiceScopeFactory scopeFactory, ILogger<EmailDigestWorker> logger)
    {
        _scopeFactory = scopeFactory;
        _logger = logger;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        _logger.LogInformation("EmailDigestWorker đã khởi động.");

        while (!stoppingToken.IsCancellationRequested)
        {
            var now = DateTime.UtcNow;
            // Chờ đến 7:00 AM UTC hôm nay hoặc ngày mai
            var nextRun = now.Date.AddHours(7);
            if (now >= nextRun) nextRun = nextRun.AddDays(1);

            var delay = nextRun - now;
            _logger.LogInformation("Digest tiếp theo lúc {NextRun}", nextRun);

            await Task.Delay(delay, stoppingToken);

            if (!stoppingToken.IsCancellationRequested)
                await SendDailyDigestAsync(stoppingToken);
        }
    }

    private async Task SendDailyDigestAsync(CancellationToken ct)
    {
        await using var scope = _scopeFactory.CreateAsyncScope();
        var db = scope.ServiceProvider.GetRequiredService<CrmDbContext>();
        var emailService = scope.ServiceProvider.GetRequiredService<IEmailService>();

        // Lấy leads mới trong 24h
        var since = DateTime.UtcNow.AddDays(-1);
        var newLeads = await db.Customers
            .Where(c => c.Status == "lead" && c.CreatedAt >= since)
            .CountAsync(ct);

        var salesUsers = await db.Users
            .Where(u => u.Role == "sales" && u.DigestEnabled)
            .ToListAsync(ct);

        foreach (var user in salesUsers)
        {
            await emailService.SendAsync(new EmailMessage
            {
                To = user.Email,
                Subject = $"CRM Digest — {newLeads} leads mới hôm nay",
                Body = $"Xin chào {user.Name}, có {newLeads} leads mới trong 24h qua."
            });
        }

        _logger.LogInformation("Đã gửi digest cho {Count} users.", salesUsers.Count);
    }
}
```

> `BackgroundService` chạy trong cùng process với API. Nếu cần isolation, tạo **Worker Service** project riêng và deploy độc lập. Với tác vụ phức tạp, cân nhắc **Hangfire** hoặc **Quartz.NET** để có UI quản lý job.

## Thực hành

### Bài 1: Customer REST API đầy đủ CRUD với Pagination + Filter + Sort

Implement `CustomersController` với các endpoints:

- `GET /api/v1/customers` — danh sách với `CustomerFilterParams` (search, status, createdFrom/To, sortBy, sortDir, page, pageSize).
- `GET /api/v1/customers/{id}` — chi tiết một customer.
- `POST /api/v1/customers` — tạo mới, trả về `201 Created` với `Location` header.
- `PUT /api/v1/customers/{id}` — cập nhật toàn bộ.
- `PATCH /api/v1/customers/{id}` — cập nhật một phần (dùng `JsonPatchDocument` hoặc request DTO riêng).
- `DELETE /api/v1/customers/{id}` — xóa, trả về `204 No Content`.

Yêu cầu:
- Response envelope `PagedResponse<CustomerDto>` cho danh sách.
- Validation với Data Annotations hoặc FluentValidation.
- Global exception handler trả về `ProblemDetails`.
- Swagger với XML comments và `ProducesResponseType` đầy đủ.

### Bài 2: File Upload API cho Avatar và Document Attachment

Implement các endpoints:

- `POST /api/v1/customers/{id}/avatar` — upload ảnh đại diện (JPEG/PNG/WebP, max 5MB).
- `DELETE /api/v1/customers/{id}/avatar` — xóa avatar.
- `POST /api/v1/customers/{id}/documents` — upload nhiều file đính kèm (PDF, DOCX, max 20MB mỗi file).
- `GET /api/v1/customers/{id}/documents` — danh sách tài liệu.
- `GET /api/v1/customers/{id}/documents/{docId}/download` — download file với streaming.

Yêu cầu:
- Validate content type và kích thước file.
- Lưu vào thư mục `wwwroot/uploads/` với tên file an toàn (GUID-based).
- Trả về URL có thể truy cập công khai.
- (Nâng cao) Tích hợp Azure Blob Storage với `Azure.Storage.Blobs`.

### Bài 3: Integration Test với WebApplicationFactory cho Customer API

Viết test suite với `xUnit` và `WebApplicationFactory`:

- **Happy path:** tạo customer → lấy danh sách → lấy chi tiết → cập nhật → xóa.
- **Validation:** POST với email sai format, tên rỗng → expect `422`.
- **Not found:** GET/PUT/DELETE với ID không tồn tại → expect `404`.
- **Pagination:** GET với `page=2&pageSize=5`, verify `pagination.page == 2`.
- **Filter:** seed 10 customers với status `lead`, filter `?status=lead`, verify count.
- **Sort:** seed customers với tên khác nhau, sort `?sortBy=name&sortDir=asc`, verify thứ tự.

Yêu cầu:
- Dùng in-memory database, seed data trong constructor hoặc `IAsyncLifetime`.
- Mỗi test class có database riêng biệt (tránh test interference).
- Assert cả status code lẫn body response.
