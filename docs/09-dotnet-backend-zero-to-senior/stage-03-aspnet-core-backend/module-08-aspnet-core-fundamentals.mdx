## 1. Kiến trúc ASP.NET Core

### Từ .NET Framework sang .NET Core — Breaking Change

.NET Framework là Windows-only, IIS-only, monolithic pipeline. ASP.NET Core được viết lại hoàn toàn từ đầu: cross-platform, modular, high-performance, và có thể self-host mà không cần IIS.

| Đặc điểm | ASP.NET (.NET Framework) | ASP.NET Core |
|---|---|---|
| Platform | Windows only | Windows, Linux, macOS |
| Web server | IIS bắt buộc | Kestrel (built-in), IIS, Nginx |
| Pipeline | `HttpModule` / `HttpHandler` | Middleware chain |
| DI | Không built-in | Built-in `IServiceCollection` |
| Performance | Trung bình | Top tier (TechEmpower benchmarks) |
| Hosting model | `Global.asax`, `web.config` | `Program.cs` minimal model |

### WebApplication và Kestrel

Kestrel là HTTP server mặc định của ASP.NET Core, viết bằng libuv/Socket, không phụ thuộc IIS. Trong production, Kestrel thường đứng sau reverse proxy (Nginx, IIS, YARP).

### Minimal Hosting Model (Program.cs)

Từ .NET 6+, `Startup.cs` bị bỏ hoàn toàn — tất cả nằm trong `Program.cs`:

```csharp
// Program.cs — .NET 6+ minimal hosting model
var builder = WebApplication.CreateBuilder(args);

// 1. Đăng ký services (DI container)
builder.Services.AddControllers();
builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();

var app = builder.Build();

// 2. Cấu hình middleware pipeline
if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}

app.UseHttpsRedirection();
app.UseAuthorization();
app.MapControllers();

app.Run();
```

`WebApplication.CreateBuilder(args)` tự động:
- Load `appsettings.json` và `appsettings.{Environment}.json`
- Đọc environment variables và command-line args
- Cấu hình Kestrel từ config
- Khởi tạo DI container

## 2. Request Pipeline và Middleware

### Cách pipeline hoạt động

Request HTTP đi qua một chuỗi middleware theo thứ tự đăng ký, mỗi middleware có thể:
- Xử lý request rồi **chuyển tiếp** (`await next(context)`)
- **Dừng** pipeline (short-circuit) và trả response ngay

```
Request → [MW1] → [MW2] → [MW3] → Handler
Response ← [MW1] ← [MW2] ← [MW3] ←
```

### Use, Run, Map

```csharp
// Use — xử lý rồi chuyển tiếp
app.Use(async (context, next) =>
{
    // Trước khi xử lý
    await next(context);
    // Sau khi xử lý
});

// Run — terminal middleware, KHÔNG gọi next
app.Run(async context =>
{
    await context.Response.WriteAsync("Hello from terminal middleware");
});

// Map — rẽ nhánh theo path
app.Map("/health", branch =>
{
    branch.Run(async context =>
        await context.Response.WriteAsync("Healthy"));
});
```

### Viết Custom Middleware — Request Timing

```csharp
// Middleware/RequestTimingMiddleware.cs
public class RequestTimingMiddleware
{
    private readonly RequestDelegate _next;
    private readonly ILogger<RequestTimingMiddleware> _logger;

    public RequestTimingMiddleware(RequestDelegate next,
        ILogger<RequestTimingMiddleware> logger)
    {
        _next = next;
        _logger = logger;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        var stopwatch = Stopwatch.StartNew();
        try
        {
            await _next(context);
        }
        finally
        {
            stopwatch.Stop();
            _logger.LogInformation(
                "HTTP {Method} {Path} responded {StatusCode} in {Elapsed}ms",
                context.Request.Method,
                context.Request.Path,
                context.Response.StatusCode,
                stopwatch.ElapsedMilliseconds);
        }
    }
}

// Extension method để đăng ký
public static class RequestTimingMiddlewareExtensions
{
    public static IApplicationBuilder UseRequestTiming(
        this IApplicationBuilder builder)
        => builder.UseMiddleware<RequestTimingMiddleware>();
}
```

### Viết Custom Middleware — Correlation ID

```csharp
// Middleware/CorrelationIdMiddleware.cs
public class CorrelationIdMiddleware
{
    private const string CorrelationIdHeader = "X-Correlation-ID";
    private readonly RequestDelegate _next;

    public CorrelationIdMiddleware(RequestDelegate next) => _next = next;

    public async Task InvokeAsync(HttpContext context)
    {
        var correlationId = context.Request.Headers[CorrelationIdHeader].FirstOrDefault()
            ?? Guid.NewGuid().ToString();

        context.Items["CorrelationId"] = correlationId;
        context.Response.Headers[CorrelationIdHeader] = correlationId;

        // Đẩy vào LogContext để mọi log trong request đều có correlation ID
        using (LogContext.PushProperty("CorrelationId", correlationId))
        {
            await _next(context);
        }
    }
}
```

### Thứ tự middleware quan trọng

```csharp
// THỨ TỰ ĐÚNG trong Program.cs
app.UseExceptionHandler("/error"); // Phải đứng ĐẦU để bắt mọi exception
app.UseMiddleware<CorrelationIdMiddleware>(); // Correlation ID sớm để log được
app.UseRequestTiming();             // Timing sau correlation
app.UseHttpsRedirection();
app.UseRouting();
app.UseAuthentication();            // Authn trước Authz
app.UseAuthorization();
app.MapControllers();
```

## 3. Routing

### Attribute Routing (khuyến nghị cho API)

```csharp
[ApiController]
[Route("api/v1/[controller]")] // => api/v1/customers
public class CustomersController : ControllerBase
{
    [HttpGet]                         // GET api/v1/customers
    public IActionResult GetAll() { ... }

    [HttpGet("{id:int}")]             // GET api/v1/customers/5
    public IActionResult GetById(int id) { ... }

    [HttpGet("{id:int}/orders")]      // GET api/v1/customers/5/orders
    public IActionResult GetOrders(int id) { ... }

    [HttpPost]                        // POST api/v1/customers
    public IActionResult Create([FromBody] CreateCustomerRequest request) { ... }

    [HttpPut("{id:int}")]             // PUT api/v1/customers/5
    public IActionResult Update(int id, [FromBody] UpdateCustomerRequest request) { ... }

    [HttpDelete("{id:int}")]          // DELETE api/v1/customers/5
    public IActionResult Delete(int id) { ... }
}
```

### Route Constraints

| Constraint | Ví dụ | Mô tả |
|---|---|---|
| `int` | `{id:int}` | Số nguyên |
| `guid` | `{id:guid}` | GUID |
| `minlength(n)` | `{name:minlength(3)}` | Chuỗi tối thiểu n ký tự |
| `range(min,max)` | `{age:range(0,120)}` | Số trong khoảng |
| `regex(pattern)` | `{code:regex(^[A-Z]{{3}}$)}` | Regex |

### Minimal API (so sánh brief)

```csharp
// Minimal API — phù hợp microservice nhỏ, không cần controller class
app.MapGet("/api/v1/customers", async (ICustomerService svc) =>
    Results.Ok(await svc.GetAllAsync()));

app.MapGet("/api/v1/customers/{id:int}", async (int id, ICustomerService svc) =>
    await svc.GetByIdAsync(id) is { } customer
        ? Results.Ok(customer)
        : Results.NotFound());

app.MapPost("/api/v1/customers", async (CreateCustomerRequest req, ICustomerService svc) =>
{
    var customer = await svc.CreateAsync(req);
    return Results.CreatedAtRoute("GetCustomer", new { id = customer.Id }, customer);
});
```

Minimal API phù hợp khi cần code ít, không cần filter phức tạp. Controller vẫn là lựa chọn tốt hơn cho API lớn với nhiều action, filter, và versioning.

## 4. Controllers và Actions

### ControllerBase so với Controller

- `ControllerBase`: Dành cho **Web API** — không có View support
- `Controller`: Kế thừa `ControllerBase` + thêm View/Razor support — dùng cho MVC app

Luôn dùng `ControllerBase` cho API project.

### [ApiController] Attribute

`[ApiController]` tự động:
- Bật automatic model validation (không cần kiểm tra `ModelState.IsValid` thủ công)
- Binding source inference (`[FromBody]` cho complex type, `[FromRoute]` cho route param)
- Trả `ValidationProblemDetails` khi validation fail (HTTP 400)

### Model Binding

```csharp
[ApiController]
[Route("api/v1/customers")]
public class CustomersController : ControllerBase
{
    // [FromRoute] — từ URL path
    [HttpGet("{id:int}")]
    public IActionResult GetById([FromRoute] int id) { ... }

    // [FromQuery] — từ query string ?page=1&pageSize=20
    [HttpGet]
    public IActionResult GetAll(
        [FromQuery] int page = 1,
        [FromQuery] int pageSize = 20,
        [FromQuery] string? search = null) { ... }

    // [FromBody] — từ JSON body (POST/PUT)
    [HttpPost]
    public IActionResult Create([FromBody] CreateCustomerRequest request) { ... }

    // [FromHeader] — từ HTTP header
    [HttpPost("import")]
    public IActionResult Import(
        [FromHeader(Name = "X-Import-Source")] string importSource,
        [FromBody] ImportCustomersRequest request) { ... }
}
```

## 5. Model Validation

### DataAnnotations

```csharp
// Models/Requests/CreateCustomerRequest.cs
public class CreateCustomerRequest
{
    [Required(ErrorMessage = "Tên khách hàng là bắt buộc")]

    [Phone]
    [MaxLength(20)]
    public string? Phone { get; set; }

    public decimal CreditLimit { get; set; }
```

### Custom Validator

```csharp
public class FutureDateAttribute : ValidationAttribute
{
    protected override ValidationResult? IsValid(object? value, ValidationContext ctx)
    {
        if (value is DateTime date && date <= DateTime.UtcNow)
            return new ValidationResult("Ngày phải trong tương lai");
        return ValidationResult.Success;
    }
}
```

## 7. Logging với Serilog

### Cài đặt

```xml
<!-- CrmApi.csproj -->
<PackageReference Include="Serilog.AspNetCore" Version="8.*" />
<PackageReference Include="Serilog.Sinks.Console" Version="5.*" />
<PackageReference Include="Serilog.Sinks.File" Version="5.*" />
<PackageReference Include="Serilog.Enrichers.Environment" Version="2.*" />
<PackageReference Include="Serilog.Enrichers.Thread" Version="3.*" />
```

### Cấu hình trong Program.cs

```csharp
// Program.cs
builder.Host.UseSerilog((ctx, services, config) =>
{
    config
        .ReadFrom.Configuration(ctx.Configuration)
        .ReadFrom.Services(services)
        .Enrich.FromLogContext()
        .Enrich.WithMachineName()
        .Enrich.WithThreadId()
        .WriteTo.Console(new JsonFormatter())
        .WriteTo.File(
            path: "logs/crm-.log",
            rollingInterval: RollingInterval.Day,
            retainedFileCountLimit: 30,
            formatter: new JsonFormatter());
});

// Middleware log HTTP request (dùng Serilog built-in)
app.UseSerilogRequestLogging(options =>
{
    options.MessageTemplate =
        "HTTP {RequestMethod} {RequestPath} responded {StatusCode} in {Elapsed:0.0000}ms";
    options.EnrichDiagnosticContext = (diagnosticContext, httpContext) =>
    {
        diagnosticContext.Set("RequestHost", httpContext.Request.Host.Value);
        diagnosticContext.Set("UserAgent", httpContext.Request.Headers["User-Agent"]);
    };
});
```

### Structured Logging trong Code

```csharp
// ĐÚNG — structured, queryable
_logger.LogInformation(
    "Customer {CustomerId} created by {UserId} at {CreatedAt}",
    customer.Id, userId, DateTime.UtcNow);

// SAI — string interpolation, không queryable
_logger.LogInformation($"Customer {customer.Id} created"); // Tránh!

// CẢNH BÁO — không log sensitive data
_logger.LogDebug("Processing payment for {CardNumber}", "****-****-****-1234"); // OK
// _logger.LogDebug("Card: {CardNumber}", realCardNumber); // KHÔNG BAO GIỜ!
```

### Log Levels

| Level | Khi nào dùng |
|---|---|
| `Trace` | Rất chi tiết, chỉ debug local |
| `Debug` | Debug thông tin, không dùng ở production |
| `Information` | Request vào/ra, business event chính |
| `Warning` | Lỗi có thể phục hồi, retry, không mong đợi |
| `Error` | Lỗi không phục hồi trong một request |
| `Critical` | Ứng dụng sắp crash, cần alert ngay |

## 8. Global Exception Handling

### Cách 1: IExceptionHandler (.NET 8+, khuyến nghị)

```csharp
// ExceptionHandlers/GlobalExceptionHandler.cs
public class GlobalExceptionHandler : IExceptionHandler
{
    private readonly ILogger<GlobalExceptionHandler> _logger;

    public GlobalExceptionHandler(ILogger<GlobalExceptionHandler> logger)
        => _logger = logger;

    public async ValueTask<bool> TryHandleAsync(
        HttpContext context,
        Exception exception,
        CancellationToken cancellationToken)
    {
        var (statusCode, title) = exception switch
        {
            NotFoundException => (StatusCodes.Status404NotFound, "Resource not found"),
            ValidationException => (StatusCodes.Status422UnprocessableEntity, "Validation failed"),
            UnauthorizedAccessException => (StatusCodes.Status403Forbidden, "Access denied"),
            _ => (StatusCodes.Status500InternalServerError, "An unexpected error occurred")
        };

        // Log đầy đủ server-side, nhưng KHÔNG trả stack trace cho client
        _logger.LogError(exception,
            "Unhandled exception {ExceptionType}: {Message}",
            exception.GetType().Name, exception.Message);

        var problemDetails = new ProblemDetails
        {
            Status = statusCode,
            Title = title,
            // Chỉ trả detail ở non-production
            Detail = context.RequestServices
                .GetRequiredService<IHostEnvironment>().IsProduction()
                ? null
                : exception.Message,
            Instance = context.Request.Path
        };

        // Thêm correlation ID vào response
        if (context.Items.TryGetValue("CorrelationId", out var corrId))
            problemDetails.Extensions["correlationId"] = corrId;

        context.Response.StatusCode = statusCode;
        await context.Response.WriteAsJsonAsync(problemDetails, cancellationToken);
        return true;
    }
}

// Program.cs
builder.Services.AddExceptionHandler<GlobalExceptionHandler>();
builder.Services.AddProblemDetails();

app.UseExceptionHandler(); // Phải đứng đầu pipeline
```

## 9. Health Checks

```csharp
// Program.cs
builder.Services.AddHealthChecks()
    .AddCheck("self", () => HealthCheckResult.Healthy("API is running"))
    .AddSqlServer(
        connectionString: builder.Configuration.GetConnectionString("CrmDb")!,
        name: "database",
        tags: ["db", "sql"]);

// Custom health check
public class ExternalApiHealthCheck : IHealthCheck
{
    private readonly HttpClient _httpClient;

    public ExternalApiHealthCheck(HttpClient httpClient)
        => _httpClient = httpClient;

    public async Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context,
        CancellationToken cancellationToken = default)
    {
        try
        {
            var response = await _httpClient.GetAsync("/ping", cancellationToken);
            return response.IsSuccessStatusCode
                ? HealthCheckResult.Healthy("External API is reachable")
                : HealthCheckResult.Degraded("External API returned non-success status");
        }
        catch (Exception ex)
        {
            return HealthCheckResult.Unhealthy("External API is unreachable", ex);
        }
    }
}

// Endpoint mapping
app.MapHealthChecks("/health", new HealthCheckOptions
{
    ResponseWriter = UIResponseWriter.WriteHealthCheckUIResponse
});

// Endpoint chi tiết hơn (chỉ cho internal network)
app.MapHealthChecks("/health/detail", new HealthCheckOptions
{
    Predicate = _ => true,
    ResponseWriter = UIResponseWriter.WriteHealthCheckUIResponse
}).RequireHost("localhost");
```

### Bài 2: Serilog + Correlation ID Middleware

**Yêu cầu:** Tích hợp Serilog structured logging, thêm correlation ID middleware để mỗi request log đều có `CorrelationId`.

```csharp
// Program.cs — thêm Serilog
builder.Host.UseSerilog((ctx, _, config) =>
    config.ReadFrom.Configuration(ctx.Configuration)
          .Enrich.FromLogContext()
```

### Bài 3: CustomersController — API đầu tiên của CRM

**Yêu cầu:** Xây dựng `CustomersController` với GET list (có phân trang) và GET by id, xử lý `NotFoundException` qua `GlobalExceptionHandler`.

```csharp
// Models/Customer.cs
public class Customer
{
    public int Id { get; set; }
    public string Name { get; set; } = default!;
    public string Email { get; set; } = default!;
    public string? Phone { get; set; }
    public decimal CreditLimit { get; set; }
    public DateTime CreatedAt { get; set; }
}

// Models/Requests/GetCustomersRequest.cs
public class GetCustomersRequest
{
    [Range(1, int.MaxValue)] public int Page { get; set; } = 1;
    [Range(1, 100)] public int PageSize { get; set; } = 20;
    public string? Search { get; set; }
}

// Models/Responses/PagedResponse.cs
public class PagedResponse<T>
{
    public IReadOnlyList<T> Items { get; init; } = [];
    public int Page { get; init; }
    public int PageSize { get; init; }
    public int TotalCount { get; init; }
    public int TotalPages => (int)Math.Ceiling((double)TotalCount / PageSize);
}

// Controllers/CustomersController.cs
[ApiController]
[Route("api/v1/[controller]")]
[Produces("application/json")]
public class CustomersController : ControllerBase
{
    // Dữ liệu in-memory tạm, sẽ thay bằng EF Core ở Module sau
    private static readonly List<Customer> _store =
    [
        new() { Id = 1, Name = "Nguyễn Văn A", Email = "a@example.com",
                Phone = "0901234567", CreditLimit = 50_000_000, CreatedAt = DateTime.UtcNow.AddDays(-30) },
        new() { Id = 2, Name = "Trần Thị B", Email = "b@example.com",
                CreditLimit = 100_000_000, CreatedAt = DateTime.UtcNow.AddDays(-10) },
    ];

    private readonly ILogger<CustomersController> _logger;

    public CustomersController(ILogger<CustomersController> logger)
        => _logger = logger;

    /// <summary>Lấy danh sách khách hàng có phân trang và tìm kiếm</summary>
    [HttpGet]
    [ProducesResponseType(typeof(PagedResponse<Customer>), StatusCodes.Status200OK)]
    public ActionResult<PagedResponse<Customer>> GetAll([FromQuery] GetCustomersRequest request)
    {
        var query = _store.AsQueryable();

        if (!string.IsNullOrWhiteSpace(request.Search))
            query = query.Where(c =>
                c.Name.Contains(request.Search, StringComparison.OrdinalIgnoreCase) ||
                c.Email.Contains(request.Search, StringComparison.OrdinalIgnoreCase));

        var totalCount = query.Count();
        var items = query
            .Skip((request.Page - 1) * request.PageSize)
            .Take(request.PageSize)
            .ToList();

        _logger.LogInformation(
            "GetAll customers: page={Page}, pageSize={PageSize}, total={Total}",
            request.Page, request.PageSize, totalCount);

        return Ok(new PagedResponse<Customer>
        {
            Items = items,
            Page = request.Page,
            PageSize = request.PageSize,
            TotalCount = totalCount
        });
    }

    /// <summary>Lấy thông tin một khách hàng theo ID</summary>
    [HttpGet("{id:int}", Name = "GetCustomerById")]
    [ProducesResponseType(typeof(Customer), StatusCodes.Status200OK)]
    [ProducesResponseType(typeof(ProblemDetails), StatusCodes.Status404NotFound)]
    public ActionResult<Customer> GetById([FromRoute] int id)
    {
        var customer = _store.FirstOrDefault(c => c.Id == id)
            ?? throw new NotFoundException(nameof(Customer), id);

        return Ok(customer);
    }
}
```

**Kiểm tra:**
- `GET /api/v1/customers` → danh sách 2 khách hàng
- `GET /api/v1/customers?search=Nguyễn` → lọc theo tên
- `GET /api/v1/customers/1` → khách hàng id=1
- `GET /api/v1/customers/999` → `404 ProblemDetails` không có stack trace

## Tóm tắt

| Khái niệm | Điểm chính |
|---|---|
| Minimal Hosting | `Program.cs` duy nhất, `WebApplication.CreateBuilder` |
| Middleware | Thứ tự quan trọng; Exception handler phải đứng đầu |
| Routing | Attribute routing cho API; route constraints giữ type safety |
| Controller | Dùng `ControllerBase` + `[ApiController]`; không cần check `ModelState` |
| Model Binding | `[FromRoute]`, `[FromQuery]`, `[FromBody]`, `[FromHeader]` |
| Validation | DataAnnotations + tự động `ProblemDetails` 400 |
| Configuration | Options pattern + User Secrets; không commit secret |
| Logging | Serilog structured logging; không log sensitive data |
| Exception | `IExceptionHandler` (.NET 8+); không trả stack trace ở production |
| Health Check | `/health` endpoint cho Docker/K8s liveness và readiness probe |

**Chuyển tiếp Module 9:** Bây giờ bạn đã có controller và pipeline hoàn chỉnh. Module tiếp theo sẽ kết nối thực sự với database qua **Entity Framework Core** — thay thế `_store` in-memory bằng SQL Server, viết migrations, và xây dựng Repository pattern cho CRM.
