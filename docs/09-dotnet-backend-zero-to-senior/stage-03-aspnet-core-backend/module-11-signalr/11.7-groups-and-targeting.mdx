# 11.7 — 6. Groups và Targeting

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### 11.7.1 — Chiến lược nhóm trong CRM

```csharp
public class CrmNotificationHub : Hub<ICrmNotificationClient>
{
    // Gửi cho toàn bộ tenant
    public async Task NotifyTenant(string tenantId, NotificationDto notification)
    {
        await Clients.Group($"tenant-{tenantId}").ReceiveNotification(notification);
    }

    // Gửi cho một team cụ thể
    public async Task NotifyTeam(string tenantId, string teamId, NotificationDto notification)
    {
        var groupName = $"tenant-{tenantId}-team-{teamId}";
        await Clients.Group(groupName).ReceiveNotification(notification);
    }

    // Gửi cho một user cụ thể (dù đang đăng nhập từ nhiều thiết bị)
    public async Task NotifyUser(string userId, NotificationDto notification)
    {
        // Clients.User tự tập hợp tất cả connection của userId đó
        await Clients.User(userId).ReceiveNotification(notification);
    }

    // Ví dụ thực tế: Sales team của tenant X vừa có deal mới
    public async Task BroadcastNewDeal(string tenantId, string teamId, DealDto deal)
    {
        var notification = new NotificationDto
        {
            Id = Guid.NewGuid(),
            Message = $"Deal mới: {deal.Name} — {deal.Value:C}",
            Type = NotificationType.Success,
            CreatedAt = DateTime.UtcNow
        };

        // Chỉ sales team của tenant đó nhận được
        await Clients.Group($"tenant-{tenantId}-team-{teamId}")
                     .ReceiveNotification(notification);
    }
}
```

### 11.7.2 — Quản lý group membership động

```csharp
// Khi nhân viên đổi team → cập nhật group membership
public async Task SwitchTeam(string tenantId, string oldTeamId, string newTeamId)
{
    var oldGroup = $"tenant-{tenantId}-team-{oldTeamId}";
    var newGroup = $"tenant-{tenantId}-team-{newTeamId}";

    await Groups.RemoveFromGroupAsync(Context.ConnectionId, oldGroup);
    await Groups.AddToGroupAsync(Context.ConnectionId, newGroup);
}
```
