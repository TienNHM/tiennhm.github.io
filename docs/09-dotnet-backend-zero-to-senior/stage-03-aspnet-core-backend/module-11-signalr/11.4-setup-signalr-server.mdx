# 11.4 — 3. Setup SignalR Server

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### 11.4.1 — Cài đặt và cấu hình

```csharp
// Program.cs
builder.Services.AddSignalR(options =>
{
    options.EnableDetailedErrors = builder.Environment.IsDevelopment();
    options.KeepAliveInterval = TimeSpan.FromSeconds(15);
    options.ClientTimeoutInterval = TimeSpan.FromSeconds(30);
});

// Map hub endpoint
app.MapHub<CrmNotificationHub>("/hubs/notifications");
```

### 11.4.2 — Strongly-typed Hub với Interface

Strongly-typed Hub giúp compile-time safety — tránh typo khi gọi client method.

```csharp
// Interface định nghĩa các method mà SERVER có thể GỌI trên CLIENT
public interface ICrmNotificationClient
{
    Task ReceiveNotification(NotificationDto notification);
    Task ReceiveLeadUpdate(LeadUpdateDto update);
    Task UserStatusChanged(string userId, bool isOnline);
}

// Hub strongly-typed
public class CrmNotificationHub : Hub<ICrmNotificationClient>
{
    private readonly ILogger<CrmNotificationHub> _logger;
    private readonly IPresenceTracker _presenceTracker;

    public CrmNotificationHub(
        ILogger<CrmNotificationHub> logger,
        IPresenceTracker presenceTracker)
    {
        _logger = logger;
        _presenceTracker = presenceTracker;
    }

    // Method CLIENT có thể GỌI lên SERVER
    public async Task JoinTenantGroup(string tenantId)
    {
        var userId = Context.UserIdentifier!;
        await Groups.AddToGroupAsync(Context.ConnectionId, $"tenant-{tenantId}");
        _logger.LogInformation("User {UserId} joined tenant group {TenantId}", userId, tenantId);
    }

    public async Task LeaveGroup(string groupName)
    {
        await Groups.RemoveFromGroupAsync(Context.ConnectionId, groupName);
    }

    // Gọi thẳng tới client gọi method này (echo test)
    public async Task Ping()
    {
        await Clients.Caller.ReceiveNotification(new NotificationDto
        {
            Id = Guid.NewGuid(),
            Message = "Pong from server!",
            Type = NotificationType.Info,
            CreatedAt = DateTime.UtcNow
        });
    }
}
```
