## 1. Tại sao cần Real-time?

### So sánh các kỹ thuật

| Kỹ thuật | Cách hoạt động | Latency | Overhead | Hướng |
|---|---|---|---|---|
| **Short Polling** | Client gửi request định kỳ (mỗi 5s) | Cao | Rất cao | Client → Server |
| **Long Polling** | Client gửi request, server giữ kết nối đến khi có data | Trung bình | Cao | Client ↔ Server |
| **Server-Sent Events (SSE)** | Server push liên tục qua một kết nối HTTP | Thấp | Thấp | Server → Client |
| **WebSocket** | Kết nối 2 chiều, persistent, full-duplex | Rất thấp | Rất thấp | Bidirectional |
| **SignalR** | Wrapper thông minh, tự chọn transport tốt nhất | Rất thấp | Thấp | Bidirectional |

**SignalR** không phải là một protocol riêng — nó là một abstraction layer tự động negotiate transport theo thứ tự ưu tiên: **WebSocket > SSE > Long Polling**.

### Use cases trong CRM

- **Notification center**: Lead mới được assign → push ngay cho nhân viên sales
- **Live dashboard**: Số liệu doanh thu, lead pipeline cập nhật real-time
- **Typing indicator**: Nhân viên đang nhập comment trong ticket support
- **Presence**: Ai đang xem cùng hồ sơ khách hàng
- **Approval flow**: Manager vừa duyệt đề xuất → notify người gửi ngay lập tức

## 2. SignalR Architecture

### Các thành phần cốt lõi

```
Client (JS/TS)                  Server (ASP.NET Core)
    │                                    │
    │──── negotiate ──────────────────→  │
    │←─── connectionId, transports ────  │
    │                                    │
    │══════ WebSocket connection ═══════ │
    │                                    │
    │──── InvokeMethod("Send", args) →   Hub
    │                        ↓           │
    │←── ReceiveMessage(data) ──────── Hub
    │                                    │
```

**Hub**: Là class trung tâm, xử lý tất cả communication. Mỗi kết nối có `Context.ConnectionId` duy nhất.

**Transport Negotiation**: SignalR thử theo thứ tự:
1. WebSocket (nhanh nhất, cần HTTP/1.1 upgrade)
2. Server-Sent Events (nếu WebSocket bị block)
3. Long Polling (fallback cuối cùng)

**Group**: Nhóm các connection lại để broadcast. Ví dụ: group `tenant-123`, group `sales-team`.

**HubContext**: Interface cho phép code ngoài Hub (service, background job) gửi message tới client.

```csharp
public class CrmNotificationHub : Hub<ICrmNotificationClient>
```

### Cài đặt package


### TypeScript client

```typescript
// src/services/notificationHubService.ts
import * as signalR from "@microsoft/signalr";

export interface NotificationDto {
  id: string;
  message: string;
  type: "info" | "success" | "warning" | "error";
  createdAt: string;
  isRead: boolean;
}

export class NotificationHubService {
  private connection: signalR.HubConnection;

  constructor(private getToken: () => string) {
    this.connection = new signalR.HubConnectionBuilder()
      .withUrl("/hubs/notifications", {
        // JWT được gửi qua query string (WebSocket không hỗ trợ header)
        accessTokenFactory: () => this.getToken(),
      })
      .withAutomaticReconnect({
        nextRetryDelayInMilliseconds: (retryContext) => {
          // Exponential backoff: 0s, 2s, 10s, 30s, rồi mỗi 60s
          const delays = [0, 2000, 10000, 30000];
          return delays[retryContext.previousRetryCount] ?? 60000;
        },
      })
      .configureLogging(signalR.LogLevel.Warning)
      .build();

    this.registerEventHandlers();
  }

  private registerEventHandlers(): void {
    this.connection.onreconnecting((error) => {
      console.warn("SignalR reconnecting...", error);
    });

    this.connection.onreconnected((connectionId) => {
      console.info("SignalR reconnected:", connectionId);
      // Rejoin groups sau khi reconnect
      this.joinTenantGroup(getCurrentTenantId());
    });

    this.connection.onclose((error) => {
      console.error("SignalR connection closed:", error);
    });
  }

  async start(): Promise<void> {
    await this.connection.start();
    console.info("SignalR connected, ID:", this.connection.connectionId);
  }

  async joinTenantGroup(tenantId: string): Promise<void> {
    await this.connection.invoke("JoinTenantGroup", tenantId);
  }

  onNotification(callback: (notification: NotificationDto) => void): void {
    this.connection.on("ReceiveNotification", callback);
  }

  onLeadUpdate(callback: (update: unknown) => void): void {
    this.connection.on("ReceiveLeadUpdate", callback);
  }

  async stop(): Promise<void> {
    await this.connection.stop();
  }
}
```

## 5. Authentication trong SignalR

### Vấn đề với WebSocket và JWT

WebSocket không cho phép gửi custom header (hạn chế của browser WebSocket API). SignalR giải quyết bằng cách truyền token qua **query string** trong lần negotiate đầu tiên.

```csharp
// Program.cs — cấu hình JWT để đọc từ query string
builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuerSigningKey = true,
            IssuerSigningKey = new SymmetricSecurityKey(
                Encoding.UTF8.GetBytes(builder.Configuration["Jwt:Key"]!)),
            ValidateIssuer = true,
            ValidIssuer = builder.Configuration["Jwt:Issuer"],
            ValidateAudience = false,
            ClockSkew = TimeSpan.Zero
        };

        // Quan trọng: đọc token từ query string cho SignalR
        options.Events = new JwtBearerEvents
        {
            OnMessageReceived = context =>
            {
                var accessToken = context.Request.Query["access_token"];
                var path = context.HttpContext.Request.Path;

                if (!string.IsNullOrEmpty(accessToken) &&
                    path.StartsWithSegments("/hubs"))
                {
                    context.Token = accessToken;
                }
                return Task.CompletedTask;
            }
        };
    });
```

### Bảo vệ Hub bằng [Authorize]

```csharp
[Authorize]  // Toàn bộ Hub yêu cầu xác thực
public class CrmNotificationHub : Hub<ICrmNotificationClient>
{
    // Lấy thông tin user từ JWT claims
    private string GetCurrentUserId() =>
        Context.UserIdentifier!;  // Lấy từ claim NameIdentifier

    private string GetCurrentTenantId() =>
        Context.User!.FindFirstValue("tenantId")!;

    public override async Task OnConnectedAsync()
    {
        var userId = GetCurrentUserId();
        var tenantId = GetCurrentTenantId();

        // Tự động join vào group của tenant khi connect
        await Groups.AddToGroupAsync(Context.ConnectionId, $"tenant-{tenantId}");
        await Groups.AddToGroupAsync(Context.ConnectionId, $"user-{userId}");

        await base.OnConnectedAsync();
    }
}
```

## 7. IHubContext — Server push từ ngoài Hub

`IHubContext` cho phép code bên ngoài Hub (service layer, background job, controller) gửi message tới client mà không cần client gọi Hub trước.

### Inject IHubContext vào Service

```csharp
public class LeadService
{
    private readonly IHubContext<CrmNotificationHub, ICrmNotificationClient> _hubContext;
    private readonly ILeadRepository _leadRepo;
    private readonly INotificationRepository _notificationRepo;

    public LeadService(
        IHubContext<CrmNotificationHub, ICrmNotificationClient> hubContext,
        ILeadRepository leadRepo,
        INotificationRepository notificationRepo)
    {
        _hubContext = hubContext;
        _leadRepo = leadRepo;
        _notificationRepo = notificationRepo;
    }

    public async Task AssignLeadAsync(Guid leadId, string assigneeId, string assignedById)
    {
        // 1. Cập nhật DB
        var lead = await _leadRepo.GetByIdAsync(leadId);
        lead.AssignTo(assigneeId, assignedById);
        await _leadRepo.SaveAsync();

        // 2. Tạo notification record trong DB
        var notification = new Notification
        {
            Id = Guid.NewGuid(),
            UserId = assigneeId,
            Message = $"Lead '{lead.Name}' đã được assign cho bạn",
            Type = NotificationType.Info,
            EntityType = "Lead",
            EntityId = leadId.ToString(),
            IsRead = false,
            CreatedAt = DateTime.UtcNow
        };
        await _notificationRepo.AddAsync(notification);

        // 3. Push real-time ngay lập tức
        var dto = notification.ToDto();
        await _hubContext.Clients.User(assigneeId).ReceiveNotification(dto);
    }
}
```

### Push từ Background Job

```csharp
public class ReportGenerationJob : BackgroundService
{
    private readonly IHubContext<CrmNotificationHub, ICrmNotificationClient> _hubContext;
    private readonly IReportService _reportService;

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            // Xử lý queue job...
            var job = await _reportService.DequeueAsync(stoppingToken);
            
            try
            {
                await _reportService.GenerateAsync(job);

                // Notify user khi job hoàn thành
                await _hubContext.Clients.User(job.RequestedByUserId)
                    .ReceiveNotification(new NotificationDto
                    {
                        Id = Guid.NewGuid(),
                        Message = $"Báo cáo '{job.ReportName}' đã sẵn sàng tải xuống",
                        Type = NotificationType.Success,
                        CreatedAt = DateTime.UtcNow
                    });
            }
            catch (Exception ex)
            {
                await _hubContext.Clients.User(job.RequestedByUserId)
                    .ReceiveNotification(new NotificationDto
                    {
                        Id = Guid.NewGuid(),
                        Message = $"Tạo báo cáo thất bại: {ex.Message}",
                        Type = NotificationType.Error,
                        CreatedAt = DateTime.UtcNow
                    });
            }
        }
    }
}
```

### NotificationService

```csharp
public class NotificationService
{
    private readonly INotificationRepository _repo;
    private readonly IHubContext<CrmNotificationHub, ICrmNotificationClient> _hub;

    public NotificationService(
        INotificationRepository repo,
        IHubContext<CrmNotificationHub, ICrmNotificationClient> hub)
    {
        _repo = repo;
        _hub = hub;
    }

    public async Task SendAsync(string userId, string message,
        NotificationType type = NotificationType.Info,
        string? entityType = null, string? entityId = null)
    {
        // 1. Persist
        var notification = new Notification
        {
            Id = Guid.NewGuid(),
            UserId = userId,
            Message = message,
            Type = type,
            EntityType = entityType,
            EntityId = entityId,
            IsRead = false,
            CreatedAt = DateTime.UtcNow
        };
        await _repo.AddAsync(notification);

        // 2. Real-time push (không await blocking — fire and forget với try/catch)
        _ = _hub.Clients.User(userId)
              .ReceiveNotification(notification.ToDto())
              .ContinueWith(t =>
              {
                  if (t.IsFaulted)
                      Console.Error.WriteLine($"Push failed: {t.Exception?.Message}");
              });
    }

    public async Task MarkAsReadAsync(Guid notificationId, string userId)
    {
        var notification = await _repo.GetByIdAsync(notificationId);
        if (notification.UserId != userId)
            throw new UnauthorizedAccessException();

        notification.IsRead = true;
        notification.ReadAt = DateTime.UtcNow;
        await _repo.SaveAsync();
    }

    public async Task MarkAllAsReadAsync(string userId)
    {
        await _repo.MarkAllAsReadAsync(userId);
    }

    public async Task<List<NotificationDto>> GetUnreadAsync(string userId, int limit = 20)
    {
        var items = await _repo.GetUnreadAsync(userId, limit);
        return items.Select(n => n.ToDto()).ToList();
    }
}
```

## 9. Presence — Online/Offline

### Tracking connection state

```csharp
public interface IPresenceTracker
{
    Task UserConnectedAsync(string userId, string connectionId);
    Task UserDisconnectedAsync(string userId, string connectionId);
    Task<bool> IsOnlineAsync(string userId);
    Task<List<string>> GetOnlineUsersAsync(string tenantId);
}

// In-memory implementation (không dùng cho production multi-instance)
public class InMemoryPresenceTracker : IPresenceTracker
{
    // userId → set of connectionIds (user có thể mở nhiều tab)
    private static readonly ConcurrentDictionary<string, HashSet<string>>
        _connections = new();

    public Task UserConnectedAsync(string userId, string connectionId)
    {
        _connections.AddOrUpdate(
            userId,
            _ => new HashSet<string> { connectionId },
            (_, set) => { set.Add(connectionId); return set; });
        return Task.CompletedTask;
    }

    public Task UserDisconnectedAsync(string userId, string connectionId)
    {
        if (_connections.TryGetValue(userId, out var set))
        {
            set.Remove(connectionId);
            if (set.Count == 0)
                _connections.TryRemove(userId, out _);
        }
        return Task.CompletedTask;
    }

    public Task<bool> IsOnlineAsync(string userId) =>
        Task.FromResult(_connections.ContainsKey(userId) &&
                        _connections[userId].Count > 0);
}
```

### Override OnConnected/OnDisconnected trong Hub

```csharp
public class CrmNotificationHub : Hub<ICrmNotificationClient>
{
    private readonly IPresenceTracker _presenceTracker;

    public override async Task OnConnectedAsync()
    {
        var userId = Context.UserIdentifier!;
        var tenantId = Context.User!.FindFirstValue("tenantId")!;

        await _presenceTracker.UserConnectedAsync(userId, Context.ConnectionId);

        // Auto-join groups
        await Groups.AddToGroupAsync(Context.ConnectionId, $"tenant-{tenantId}");
        await Groups.AddToGroupAsync(Context.ConnectionId, $"user-{userId}");

        // Broadcast presence update cho tenant group
        await Clients.Group($"tenant-{tenantId}")
                     .UserStatusChanged(userId, isOnline: true);

        await base.OnConnectedAsync();
    }

    public override async Task OnDisconnectedAsync(Exception? exception)
    {
        var userId = Context.UserIdentifier!;
        var tenantId = Context.User!.FindFirstValue("tenantId")!;

        await _presenceTracker.UserDisconnectedAsync(userId, Context.ConnectionId);

        var isStillOnline = await _presenceTracker.IsOnlineAsync(userId);

        // Chỉ broadcast offline khi KHÔNG còn connection nào (đóng tất cả tab)
        if (!isStillOnline)
        {
            await Clients.Group($"tenant-{tenantId}")
                         .UserStatusChanged(userId, isOnline: false);
        }

        await base.OnDisconnectedAsync(exception);
    }
}
```

> **Lưu ý scale-out**: `InMemoryPresenceTracker` chỉ hoạt động đúng trên **một instance**. Khi deploy nhiều instance (load balancer), mỗi instance có dictionary riêng → không chính xác. Giải pháp: dùng **Redis** để lưu presence state.

## 10. Scale-out và Production

### Vấn đề với nhiều instance

```
[Client A] ─── Instance 1 ───┐
                              ├─── Backplane (Redis) ──── broadcast tới tất cả
[Client B] ─── Instance 2 ───┘
```


```csharp
// Program.cs — thay AddStackExchangeRedis bằng:
builder.Services.AddSignalR()
    .AddAzureSignalR(builder.Configuration["Azure:SignalR:ConnectionString"]!);
```

Azure SignalR Service xử lý toàn bộ infrastructure: connection management, scale-out, geo-replication — không cần tự quản lý Redis.

### Sticky Session

Khi dùng Redis backplane với nginx/load balancer, cần bật **sticky session** (IP hash hoặc session cookie) để negotiate và WebSocket upgrade đều đến cùng một instance:

```nginx
upstream signalr_backend {
    ip_hash;  # Sticky session
    server api1:5000;
    server api2:5000;
}
```

| Tier | Concurrent connections |
|---|---|
| Free (Azure SignalR) | 20 |
| Standard (Azure SignalR) | 1.000/unit |
| Self-hosted (Redis backplane) | Giới hạn bởi RAM/CPU |

## Tóm tắt

| Khái niệm | Ghi nhớ |
|---|---|
| Transport negotiation | WebSocket > SSE > Long Polling, SignalR tự chọn |
| Strongly-typed Hub | Dùng `Hub<TClient>` + interface để compile-time safety |
| JWT trong WebSocket | Truyền qua query string, đọc trong `OnMessageReceived` |
| `Groups` | Organize connections; join khi connect, leave khi disconnect |
| `IHubContext` | Push từ service/job ngoài Hub; inject `IHubContext<THub, TClient>` |
| Presence | Track `OnConnectedAsync`/`OnDisconnectedAsync`; dùng Redis khi scale |
| Scale-out | Redis backplane hoặc Azure SignalR Service; cần sticky session |

SignalR giải quyết hoàn toàn bài toán real-time cho CRM: notification center, live dashboard, và presence tracking — với developer experience tốt hơn nhiều so với WebSocket thuần nhờ transport fallback, auto-reconnect và strongly-typed API.
