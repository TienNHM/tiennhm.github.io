# 3.3 — 2. Cài đặt và cấu hình Git

## Nội dung bài học

### 3.3.1 — Cài đặt

Tải Git tại [https://git-scm.com](https://git-scm.com) và cài đặt theo hướng dẫn. Kiểm tra sau khi cài:

```bash
git --version
# git version 2.44.0.windows.1
```

### 3.3.2 — Cấu hình cơ bản

Trước tiên phải khai báo danh tính — Git dùng thông tin này để gắn tên tác giả vào mỗi commit:

```bash
git config --global user.name "Nguyen Van A"
git config --global user.email "nguyenvana@company.com"
git config --global core.editor "code --wait"   # dùng VS Code làm editor mặc định
git config --global init.defaultBranch main      # đặt nhánh mặc định là main
```

Kiểm tra cấu hình:

```bash
git config --list
```

### 3.3.3 — Kết nối GitHub qua SSH

HTTPS yêu cầu nhập mật khẩu mỗi lần push. SSH key giúp xác thực tự động — bắt buộc trong môi trường team.

```bash
# Bước 1: Tạo SSH key
ssh-keygen -t ed25519 -C "nguyenvana@company.com"
# Nhấn Enter để dùng đường dẫn mặc định (~/.ssh/id_ed25519)

# Bước 2: Lấy nội dung public key
cat ~/.ssh/id_ed25519.pub

# Bước 3: Vào GitHub → Settings → SSH and GPG keys → New SSH key
# Dán nội dung public key vào

# Bước 4: Kiểm tra kết nối
ssh -T git@github.com
# Hi nguyenvana! You've successfully authenticated...
```
