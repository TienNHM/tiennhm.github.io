# 5.5 — 4. Delegates và Events

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### 5.5.1 — 4.1 Built-in Delegates

```csharp
// Action<T>: không return giá trị
Action<string> log = msg => Console.WriteLine($"[LOG] {msg}");
Action<Customer, string> notify = (c, msg) => SendEmail(c.Email, msg);

// Func<T, TResult>: có return giá trị
Func<Lead, bool> isHot  = lead => lead.Score >= 80;
Func<decimal, decimal, decimal> add = (a, b) => a + b;

// Predicate<T>: Func<T, bool> — thường dùng với List.FindAll
Predicate<Customer> isVip = c => c.Tier == CustomerTier.VIP;
var vipList = customers.FindAll(isVip);
```

### 5.5.2 — 4.2 Custom Delegate và Event Pattern trong CRM

```csharp
// Domain event
public record CustomerStatusChangedEvent(
    int CustomerId,
    CustomerStatus OldStatus,
    CustomerStatus NewStatus,
    DateTime OccurredAt);

// Event handler delegate
public delegate Task CustomerStatusChangedHandler(CustomerStatusChangedEvent e);

// Service phát event
public class CustomerService
{
    public event CustomerStatusChangedHandler? StatusChanged;

    public async Task ChangeStatusAsync(int id, CustomerStatus newStatus)
    {
        var customer = await _repo.GetByIdAsync(id)
            ?? throw new NotFoundException($"Customer {id}");

        var oldStatus = customer.Status;
        customer.UpdateStatus(newStatus);
        await _repo.UpdateAsync(customer);

        // Phát event — subscriber tự xử lý
        if (StatusChanged is not null)
            await StatusChanged(new CustomerStatusChangedEvent(id, oldStatus, newStatus, DateTime.UtcNow));
    }
}

// Subscriber — đăng ký trong startup hoặc DI
customerService.StatusChanged += async e =>
{
    if (e.NewStatus == CustomerStatus.Churned)
        await _notificationService.AlertSalesTeamAsync(e.CustomerId);
};
```
