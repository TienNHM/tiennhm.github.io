# 5.7 — 6. Nullable Reference Types (C# 8+)

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### 6.1 Bật NRT trong Project

```xml
<!-- .csproj -->
<PropertyGroup>
  <Nullable>enable</Nullable>
  <WarningsAsErrors>nullable</WarningsAsErrors>  <!-- Optional: biến warning thành error -->
</PropertyGroup>
```

### 6.2 Phân Biệt `string` so với `string?`

```csharp
string  name  = null;   // ← compiler warning: CS8600
string? name2 = null;   // ← OK, nullable được khai báo rõ ràng

public Customer? FindByEmail(string email)  // return có thể null
    => _customers.FirstOrDefault(c => c.Email == email);
```

### 6.3 Null Safety Patterns

```csharp
// Null-conditional operator ?.
string? city = customer?.Address?.City;

// Null-coalescing ?? và ??=
string displayName = customer?.Name ?? "Khách hàng ẩn danh";
customer.Notes ??= new List<string>(); // khởi tạo nếu null

// Null-forgiving operator ! — dùng khi chắc chắn không null
var c = _repo.GetById(id)!; // bạn đảm bảo không null ở chỗ này

// Pattern matching
if (customer is not null)
    Console.WriteLine(customer.Name);

// Guard clause — idiomatic C# 10+
ArgumentNullException.ThrowIfNull(customer);

// Khai báo non-nullable property trong entity
public class Customer
{
    public required string Name  { get; init; } // C# 11 required
    public required string Email { get; init; }
    public string? Phone { get; set; }          // tùy chọn, có thể null
}
```
