# 5.8 — 7. Expression Trees và Reflection (Overview)

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### 5.8.1 — 7.1 Khi Nào Bạn Gặp

- ORMs (Entity Framework): dùng Expression Tree để dịch LINQ sang SQL
- AutoMapper, FluentValidation: dùng Reflection để map/validate tự động
- Dynamic query builder: filter theo field do user chọn

### 5.8.2 — 7.2 Dynamic Query Builder Đơn Giản

```csharp
// Xây filter expression động — gặp nhiều trong CRM report
public static IQueryable<T> WhereIf<T>(
    this IQueryable<T> query,
    bool condition,
    Expression<Func<T, bool>> predicate)
    => condition ? query.Where(predicate) : query;

// Dùng:
var leads = context.Leads
    .WhereIf(!string.IsNullOrEmpty(keyword), l => l.Name.Contains(keyword!))
    .WhereIf(minScore.HasValue, l => l.Score >= minScore!.Value)
    .WhereIf(assignedTo.HasValue, l => l.AssignedUserId == assignedTo);
```
