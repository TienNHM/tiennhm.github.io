# 4.6 — 5. Abstraction

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### 4.6.1 — Abstract class

Dùng khi có **hành vi chung** cần chia sẻ giữa các lớp con, đồng thời ép lớp con phải implement một số phần.

```csharp
// BaseEntity.cs — abstract, không instantiate trực tiếp
public abstract class BaseEntity
{
    public Guid Id { get; init; } = Guid.NewGuid();
    public DateTime CreatedAt { get; init; } = DateTime.UtcNow;
    public DateTime? UpdatedAt { get; protected set; }
    public bool IsDeleted { get; private set; }

    public void MarkUpdated() => UpdatedAt = DateTime.UtcNow;
    public void SoftDelete()
    {
        IsDeleted = true;
        MarkUpdated();
    }

    // Lớp con phải tự xác định cách hiển thị
    public abstract string GetSummary();
}
```

### 4.6.2 — Sealed class

Dùng khi **không muốn ai kế thừa tiếp** — cải thiện performance nhỏ và đảm bảo contract không bị thay đổi.

```csharp
public sealed class Money
{
    public decimal Amount { get; }
    public string Currency { get; }

    public Money(decimal amount, string currency)
    {
        if (amount < 0) throw new ArgumentException("Số tiền không âm.");
        Amount = amount;
        Currency = currency?.ToUpperInvariant()
            ?? throw new ArgumentNullException(nameof(currency));
    }

    public Money Add(Money other)
    {
        if (Currency != other.Currency)
            throw new InvalidOperationException("Không thể cộng hai loại tiền tệ khác nhau.");
        return new Money(Amount + other.Amount, Currency);
    }

    public override string ToString() => $"{Amount:N0} {Currency}";
}
```
