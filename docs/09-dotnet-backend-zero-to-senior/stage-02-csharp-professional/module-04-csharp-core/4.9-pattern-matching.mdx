# 4.9 — 8. Pattern Matching (C# 8+)

## Mục tiêu bài học

- Nắm được ý chính của bài và mối liên hệ với module.
- Áp dụng được kiến thức vào bối cảnh CRM/.NET backend.
- Sẵn sàng chuyển sang bài kế tiếp với nền tảng chắc chắn.

## Nội dung bài học

### 4.9.1 — is pattern và switch expression

```csharp
// is type pattern
public static string DescribeContact(Contact contact)
{
    if (contact is Customer c)
        return $"Khách hàng: {c.FullName}, đã chi {c.TotalSpent:C}";
    if (contact is Lead l)
        return $"Lead: {l.FullName}, trạng thái: {l.Status}";
    return $"Liên hệ: {contact.FullName}";
}

// switch expression với property pattern
public static string GetLeadPriority(Lead lead) => lead.Status switch
{
    LeadStatus.Qualified                  => "Cao — liên hệ ngay",
    LeadStatus.Contacted                  => "Trung bình — theo dõi",
    LeadStatus.New                        => "Mới — chờ phân loại",
    LeadStatus.Disqualified               => "Thấp — lưu trữ",
    LeadStatus.Converted                  => "Hoàn thành",
    _                                     => "Không xác định"
};

// Property pattern — kết hợp nhiều điều kiện
public static decimal GetDiscount(Customer customer) => customer switch
{
    { TotalSpent: > 50_000_000 }  => 0.20m,
    { TotalSpent: > 10_000_000 }  => 0.15m,
    { TotalSpent: > 2_000_000  }  => 0.10m,
    _                              => 0.05m
};

// Tuple pattern
public static string ClassifyDeal(LeadStatus status, decimal dealValue) =>
    (status, dealValue) switch
    {
        (LeadStatus.Qualified, > 100_000_000) => "Enterprise Deal",
        (LeadStatus.Qualified, > 10_000_000)  => "Mid-Market Deal",
        (LeadStatus.Qualified, _)              => "SMB Deal",
        (LeadStatus.Converted, _)              => "Closed Won",
        _                                      => "Pipeline"
    };
```
