Module 4 - Going Global

Khám phá AWS Global Infrastructure, cách chọn AWS Regions, edge locations, và infrastructure as code với AWS CloudFormation. Tìm hiểu cách đạt được high availability, elasticity và agility trên toàn cầu.

📄️ M04.01 - Introduction to Going Global

Giới thiệu về AWS Global Infrastructure và các khái niệm cơ bản về going global. Tìm hiểu cách chọn AWS Regions, giá trị của edge locations, và cách sử dụng AWS CloudFormation để streamline và automate deployment.

📄️ M04.02 - Choosing AWS Regions

Tìm hiểu cách chọn AWS Region phù hợp cho business needs của bạn. Khám phá 4 yếu tố chính: Compliance, Proximity, Feature availability, và Pricing. Hiểu về data isolation và regulatory requirements khi chọn Regions.

📄️ M04.03 - Diving Deeper into AWS Global Infrastructure

Tìm hiểu sâu hơn về AWS Global Infrastructure, bao gồm multi-Region và multi-AZ deployments, edge locations, CloudFront, và AWS Outposts. Khám phá mối quan hệ giữa Regions, Availability Zones, và edge locations.

📄️ M04.04 - Infrastructure and Automation

Tìm hiểu về Infrastructure as Code (IaC) và AWS CloudFormation. Khám phá các cách tương tác với AWS resources: Programmatic access, AWS Management Console, và Infrastructure as Code. Mô tả key features và benefits của CloudFormation.

📄️ M04.05 - Module 4 Assessment

Bài kiểm tra Module 4 - Going Global. Bạn phải đạt 80% trở lên để vượt qua module này. Bạn có thể làm lại không giới hạn số lần.

📄️ M04.06 - Module 4 Summary

Tổng kết Module 4 - Going Global. Ôn tập lại các khái niệm về AWS Global Infrastructure, cách chọn AWS Regions, edge locations, và Infrastructure as Code với AWS CloudFormation. Tìm hiểu các bước tiếp theo và tài nguyên học tập.
