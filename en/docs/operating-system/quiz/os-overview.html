Trắc nghiệm: Tổng quan hệ điều hành

Câu hỏi lấy từ đề thi cuối kỳ: chức năng hệ điều hành, system call, cơ chế ngắt, giao tiếp liên tiến trình và phân loại hệ thống.

Muốn chạm tay vào hệ điều hành ở mức thấp nhất thì xem thêm bài thực hành DOS Debug.
