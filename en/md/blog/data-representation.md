# Lý thuyết hệ thống số trong máy tính

> Nguồn: https://tiennhm.io.vn/en/blog/data-representation
> Lý thuyết hệ thống số trong máy tính: hệ nhị phân, hệ thập phân, hệ bát phân, hệ thập lục phân.

> Bài viết giới thiệu về lý thuyết hệ thống số trong máy tính, bao gồm các hệ số phổ biến như hệ nhị phân (binary), hệ thập phân (decimal), hệ bát phân (octal) và hệ thập lục phân (hexadecimal). Bài viết giải thích cách biểu diễn và chuyển đổi giữa các hệ số, giúp hiểu cách máy tính lưu trữ và xử lý dữ liệu ở cấp độ thấp. Đây là kiến thức nền tảng quan trọng trong Computer Architecture và Assembly Language.

Bài viết này giới thiệu về cách biểu diễn các hệ số trong máy tính.
