# Trắc nghiệm bộ nhớ ảo và thay trang

> Nguồn: https://tiennhm.io.vn/en/docs/operating-system/quiz/virtual-memory
> Trắc nghiệm bộ nhớ ảo - demand paging, bit valid-invalid, lỗi trang, thrashing, nghịch lý Belady và thời gian truy cập hiệu quả.

Phần lý thuyết ở đây bổ trợ cho bài [Các thuật toán thay trang](../02.page-replacement-algorithms.md) — bài đó dạy cách chạy FIFO, LRU, Optimal từng bước, còn trang này kiểm tra hiểu biết về cơ chế phía sau: bit valid-invalid, dirty bit, thrashing. Cấu trúc bảng trang và TLB nằm ở [trắc nghiệm phân trang](./06.paging.mdx).
