# Trắc nghiệm hệ thống file

> Nguồn: https://tiennhm.io.vn/en/docs/operating-system/quiz/file-system
> Trắc nghiệm hệ thống file - FCB, các lớp chức năng, volume control block, bảng FAT, giới hạn của FAT32 và NTFS.

Phần này nặng về ghi nhớ cấu trúc và con số. Ba nhóm hay bị lẫn nhất: **boot block / volume control block / file control block**, và ba giới hạn của FAT32 (file 4 GB, phân vùng 32 GB theo Windows, 2 TB lý thuyết).

Cách hệ điều hành sắp thứ tự đọc ghi xuống đĩa nằm ở [trắc nghiệm lập lịch đĩa](./08.disk-scheduling.mdx).
